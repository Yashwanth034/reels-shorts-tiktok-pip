# Privacy Policy — Reels + Shorts + TikTok PiP Controls

**Effective Date:** October 26, 2026  
**Extension Version:** 4.4.1

## 1. Overview

Reels + Shorts + TikTok PiP Controls is a Chrome extension that provides Picture-in-Picture playback and video controls for Instagram Reels, YouTube Shorts, and TikTok.

The extension operates locally within the user's browser and provides an optional, user-initiated Instagram Reels download feature.

## 2. Information Accessed

To provide its functionality, the extension may access:

- Current page URLs on supported websites.
- Video elements and playback information.
- Reel identifiers and available media URLs.
- Instagram media information needed for requested downloads.
- Temporary download identifiers and associated tab information.

This information is used for the extension's video playback, navigation, and download features.

## 3. Data Storage

The extension uses Chrome's local storage to temporarily record download tracking information, including download IDs, tab IDs, and internal request IDs.

These temporary records are removed when downloads finish.

Downloaded videos remain in the user's selected Chrome download location and standard browser download history.

## 4. Data Collection and Sharing

The extension does not send user information or analytics to developer-operated servers.

The extension does not sell personal data or include advertising or third-party analytics SDKs.

Supported websites continue to process user activity under their respective privacy policies.

User-requested Instagram Reel downloads may communicate with Instagram and Meta media servers to retrieve the selected video.

## 5. Browser Permissions

**Tabs:** Identifies supported video tabs and routes keyboard controls to the appropriate video session.

**Downloads:** Enables users to download Instagram Reels when they explicitly request them.

**Storage:** Temporarily tracks downloads using Chrome's local extension storage.

**Website access:** Enables video playback controls on Instagram, YouTube, and TikTok and retrieves Instagram media required for optional downloads.

## 6. Data Security

The extension does not operate a developer-controlled cloud database or user account service.

It does not intentionally collect or store passwords, payment information, or authentication credentials.

## 7. Chrome Web Store Limited Use

The extension's use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Information is used only to provide the functionality described in this policy.

## 8. User Control

Users can uninstall the extension at any time through Chrome's extension manager.

Users may manage downloaded files through Chrome or their operating system and configure extension shortcuts through Chrome's extension shortcut settings.

## 9. Changes to This Policy

This privacy policy may be updated if the extension's functionality or data-handling practices change.

## 10. Contact

For privacy questions or support, users may contact the developer through the support information provided on the extension's Chrome Web Store listing.
